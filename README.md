# Autopilot sandbox

A public playground for demoing [Autopilot](https://github.com/shahrestani-me/autopilot), a Linear agent
that works delegated issues end to end: implement, open a PR, wait for CI and an AI review, merge,
then check the result on the live site.

Live site: <https://kamyar-finlex.github.io/autopilot-sandbox/>

Nothing real lives here. CI checks one rule: every Markdown file starts with a `# ` heading.

See [CONTRIBUTING.md](CONTRIBUTING.md) for how changes land here.

See [HOW-IT-WORKS.md](HOW-IT-WORKS.md) for how a ticket travels from Linear to the live site.
